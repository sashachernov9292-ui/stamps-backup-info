Stamps Backup

Личный инструмент владельца для резервного копирования данных операционного портала Stamps. Он использует rclone и Google Drive API для отправки архивов с сервера в Google Drive владельца.

Инструмент предназначен для владельца и не предоставляет публичную регистрацию. Google-аккаунт подключается с согласия владельца через OAuth.

Доступ к Google Drive используется для размещения и проверки резервных копий. Данные Google Drive не используются для рекламы или обучения моделей искусственного интеллекта.
